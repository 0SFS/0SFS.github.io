on 2026-10-05. Preserve this attribution and the license link when distributing
the model or derivatives, and identify any changes to the model.

The user supplied the original `lockheed-martin-f-35b-lightning-ii.zip` archive
on 2026-10-05. The archive, extracted `source/f35-full.blend`, and four textures
are retained without modification. [archive-manifest.json](archive-manifest.json)
records their relative paths, byte sizes, and SHA-256 hashes;
[source.json](source.json) records the source and acquisition metadata.

This directory contains unchanged source assets. 0sfs's converted runtime GLB
and its modification notice are in `public/aircraft/f-35b/`; the aircraft is
selectable with a separately sourced experimental JSBSim flight model.

The publisher's description states: “This model appears in GeoFS.” That
statement concerns the visual model. It does not identify or license a flight
dynamics model, and no FDM provenance is established by these assets.
